# 03 超分辨率基础

用 DIV2K 训练、Set5 测试，从双三次基线开始，依次实现 SRCNN、ESPCN 等超分模型，比较 PSNR 和 SSIM。

|---|---|---|---|
| 1 | 问题定义、DIV2K/Set5 数据、PSNR/SSIM、双三次基线 | 完成 | Set5 32.65 dB / 0.9259，DIV2K valid 31.37 dB / 0.8998 |
| 2 | SRCNN（先放大再卷积） | 完成 | Set5 34.26 dB / 0.9416 |
| 3 | ESPCN / PixelShuffle（在低清上卷积） | 计划中 | |
| 4 | 多尺度特征超分 + ASFF / softmax 融合 | 计划中 | |
| 5 | 重建损失：MSE、SSIM、TV | 计划中 | |

## 模型

| 模型 | 结构 | 参数量 |
|---|---|---|
| SRCNN | 双三次放大后接 3 层卷积（9×9、1×1、5×5） | 20,099 |

要跑哪个模型，在 `config.py` 里设置 `MODEL_NAME`。权重、曲线和对比图都按模型名分开保存，比如 `sr_srcnn.pth`，不会互相覆盖。

## 运行

环境安装见[总 README](../README.md)。

```bash
cd 03_super_resolution
python baseline.py     # 三种插值的基线成绩 + 对比图
python train.py        # 训练，保存验证 PSNR 最高的模型，并画出曲线
python evaluate.py     # 在 Set5 上测最终成绩，保存四行对比图
```

数据集和训练好的权重都不进仓库，所以要先准备好数据（见下面的“数据”），再按顺序运行。

GPU 被别的程序占满时，在命令前加 `env CUDA_VISIBLE_DEVICES=`，改用 CPU。超分实验默认就跑 CPU。

## 文件说明

| 文件 | 作用 |
|---|---|
| `config.py` | 路径、放大倍数、patch 大小、训练参数、要跑哪个模型 |
| `metrics.py` | PSNR 和 SSIM，都只在 Y（亮度）通道上算 |
| `data.py` | 读取 DIV2K/Set5，裁 patch，现场用双三次生成低清图 |
| `baseline.py` | nearest / bilinear / bicubic 三种插值的成绩和对比图 |
| `model.py` | 模型定义：`SRCNN`（第 3 步加 `ESPCN`） |
| `train.py` | 训练，余弦退火，保存验证 PSNR 最高的模型 |
| `evaluate.py` | 在测试集上和双三次对比，保存对比图 |

详细的步骤讲解（每一步的原理、代码、检查点和常见报错）在 `docs/` 下，只在本机，没有提交到仓库。

## 数据

| 数据 | 数量 | 用途 |
|---|---|---|
| DIV2K train | 800 张 2K 自然图 | 训练，每轮随机裁 `TRAIN_REPEAT=10` 个 96×96 高清 patch |
| DIV2K valid | 100 张 | 验证，每轮用前 20 张的中心 256×256 挑模型；基线用完整 100 张 |
| Set5 | 5 张 | 最终测试，用完整图 |

- 低清图不落盘：读高清图后现场用双三次缩小（`antialias=True`），放大时 `antialias=False`。改 `SCALE` 不用重新准备数据。
- 训练 patch 96×96，对应低清 48×48；验证/测试图尺寸不一，`batch_size=1`。
- 训练 20 轮，每轮 800×10=8,000 个 patch，batch 16，共 10,000 次迭代；学习率从 1e-3 余弦退火到 1e-5。

## 结果

| 方法 | Set5 PSNR (dB) | Set5 SSIM | DIV2K valid PSNR (dB) | DIV2K valid SSIM |
|---|---|---|---|---|
| 双三次（2 倍） | 32.65 | 0.9259 | 31.37 | 0.8998 |
| SRCNN | 34.26 | 0.9416 | 32.64 | 0.9205 |

说明：

- 指标是“每张图先算一个分数，再对图平均”，不是把所有像素混在一起算一个全局 MSE。Set5 上两种算法差 3.3 dB（32.65 vs 35.96），报成绩时要写清楚用的是哪种。
- Set5 只有 5 张，单张波动大；选模型看 DIV2K valid，最终成绩才报 Set5。
- 我们这份 Set5 的图片版本和论文不同，绝对数字不能直接和论文比，看“相对双三次提高了多少”。
- SRCNN 训练了 20 轮（8,000 patch/轮，共 10,000 次迭代）：Set5 提升 +1.61 dB，DIV2K valid 提升 +1.28 dB。验证 PSNR 到最后一轮仍在缓慢上升；训练集和验证集用同样的中心 256 裁剪测，提升分别是 +1.36 dB 和 +1.39 dB，几乎一样，说明**还欠训练，不是过拟合**。加轮数还有空间。
