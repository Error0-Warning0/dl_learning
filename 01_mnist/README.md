# 01 MNIST 手写数字识别

用 PyTorch 识别 0～9 的手写数字，从数据、训练、测试到识别自己拍的照片，走完一个完整流程。目前完成了全连接网络（MLP），接下来在这里加 CNN，和它对比成绩。

## 模型

全连接网络，结构为 784 → 256 → 128 → 64 → 10，激活函数用 ReLU，共 242,762 个参数。

## 运行

环境安装见[总 README](../README.md)。

```bash
cd 01_mnist
python train.py                        # 训练，第一次运行会自动下载 MNIST
python evaluate.py                     # 在测试集上算最终准确率
python predict.py custom_data/7.jpg    # 识别一张手写照片
```

数据集和训练好的权重都没有提交到仓库，所以要先运行 `train.py`，后面两个脚本才能用。超参数在 `config.py` 里修改。

## 文件说明

| 文件 | 作用 |
|---|---|
| `config.py` | 路径、超参数和设备设置 |
| `model.py` | 模型定义 |
| `train.py` | 训练，保存验证准确率最高的模型，并画出训练曲线 |
| `evaluate.py` | 用测试集测最终成绩 |
| `predict.py` | 预处理并识别自己拍的手写照片 |
| `dataset.py` | 自己写的 Dataset，读取按类别分文件夹的图片（练习用，还没有接到 `train.py`；文件底部的测试代码用的是本机路径） |
| `check_env.py` | 打印各个依赖的版本，检查 GPU 是否可用 |
| `custom_data/` | 10 张手写数字照片，文件名就是正确答案 |

## 数据划分

| 数据 | 数量 | 用途 |
|---|---|---|
| 训练集 | 55,000 | 训练模型 |
| 验证集 | 5,000 | 每轮评估，挑出最好的模型 |
| 测试集 | 10,000 | 全部结束后测最终成绩 |

## 结果

| 模型 | 测试准确率 | 手写照片 |
|---|---|---|
| MLP | 97.96% | 8/10（把 3 认成 1，把 6 认成 8） |

## 收获

- **预处理很重要：** 手机照片直接缩小后，模型把 10 张全认成 3。加上二值化、裁剪、补成正方形、缩到 20×20 再放进 28×28 之后，才提升到 8/10。
- **过拟合：** 跑 20 轮时，大约从第 7～10 轮开始，训练准确率还在涨（到 99.7%），验证准确率却停在 97.5% 左右。
- **验证集和测试集要分开：** 验证集用来挑模型，可以反复用；测试集只在最后用，这样成绩才算数。
